INC-0001 — Comandos java y javac no encontrados

Síntoma:
- Bash responde «orden no encontrada».
- JAVA_HOME aparece vacío.

Causa probable:
- El JDK no está instalado o no está accesible desde PATH.

Conocimientos que faltaban:
- Qué es un comando.
- Qué es Bash.
- Qué es el JDK.
- Diferencia entre java y javac.
- Qué son PATH y JAVA_HOME.
- Cómo se instala software en cada sistema operativo.

Error docente detectado:
- La guía suponía un entorno ya configurado.

Material futuro:
- Guía de instalación multiplataforma.
- Árbol de diagnóstico.
- Actividad sobre variables de entorno.
- Comprobación automática del entorno.
